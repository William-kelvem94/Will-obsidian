# Legenda Geral — Como tudo está linkado

- Toda área temática (hub) deve sempre fazer backlink ao [[INDEX]].
- Todo painel central, dashboard, painel de projeto ou arquivo legado não atribuído deve ser endereçado para [[Painel-Cockpit.md]] ou [[Ideias/README.md]].
- Para áreas pessoais ([[Will-Pessoal]]), cruze para skills/conquistas/tarefas relevantes através do INDEX.
- O README.md de cada pasta deve explicar a função/nomenclatura da subpasta e crosslink aos principais hubs.

Siga as legendas (emojis/tags) para facilitar a navegação e faça sempre crosslink de páginas e MOCs centrais.
