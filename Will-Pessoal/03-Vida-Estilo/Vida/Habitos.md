# Hábitos

## Filosofia

Hábitos não são sobre disciplina férrea. São sobre **design de ambiente e intenção clara**. A rotina ideal é aquela que você consegue manter consistente por meses, não por dias.

> *"Não se eleve ao nível de suas metas. Caia ao nível de seus sistemas." — James Clear*

---

## Rituais diários

### Manhã (abertura)
| Horário | Atividade | Duração |
|:-------:|-----------|:-------:|
| 06:30-07:00 | Despertar natural (sem soneca). Água. | 10 min |
| 07:00-07:15 | Revisão do dia — o que precisa acontecer hoje. | 15 min |
| 07:15-07:45 | Leitura ou estudo técnico (cabeça fresca). | 30 min |
| 07:45-08:00 | Check-in no vault — estado de energia e foco. | 5 min |
| 08:00 | Café da manhã + início do trabalho. | — |

### Tarde (execução)
| Horário | Atividade | Duração |
|:-------:|-----------|:-------:|
| 12:00-13:00 | Pausa para almoço longe da tela. | 60 min |
| 13:00-13:15 | Reset pós-almoço — respiração ou curta caminhada. | 15 min |
| 13:15-15:00 | Bloco de foco no projeto principal. | 1h45 |
| 15:00-15:15 | Pausa ativa — alongamento, água. | 15 min |
| 15:15-17:00 | Bloco secundário (tarefas menores, ajustes, comunicação). | 1h45 |

### Noite (fechamento)
| Horário | Atividade | Duração |
|:-------:|-----------|:-------:|
| 17:00-18:00 | Encerramento do trabalho. Revisar o que foi feito. | 30 min |
| 18:00-19:00 | Atividade física ou caminhada. | 30-60 min |
| 19:00-20:30 | Jantar + lazer (série, jogo, leitura leve). | 90 min |
| 20:30-21:00 | Preparação para o dia seguinte. Planejamento mínimo. | 15 min |
| 21:00-21:30 | Desconexão — sem telas. Leitura física ou meditação. | 30 min |
| 21:30 | Dormir. | — |

## Sistema de tracking

Ritmo semanal: marco o que foi consistente.

### Diários (checklist do dia)
- [ ] ✅ Acordei no horário planejado.
- [ ] ✅ Revisão do dia feita.
- [ ] ✅ Bloco de foco no projeto principal.
- [ ] ✅ Pausas respeitadas.
- [ ] ✅ Movimento físico (qualquer coisa ≥ 20 min).
- [ ] ✅ Check-in de energia e foco registrado.
- [ ] ✅ Tela desligada 30 min antes de dormir.

### Semanais (review)
- [ ] ✅ Revisão de [[Will-Pessoal/03-Vida-Estilo/Vida/Financas|finanças]] (15 min).
- [ ] ✅ Atualização de [[Will-Pessoal/03-Vida-Estilo/Conhecimento/Leituras|leituras]] e aprendizados.
- [ ] ✅ Revisão de projetos — o que avançou, o que travou.
- [ ] ✅ Check-in de [[Will-Pessoal/03-Vida-Estilo/Vida/Saude|saúde]] — sono, estresse, alimentação.
- [ ] ✅ Planejamento da semana seguinte.

## Hábitos a quebrar

| Hábito | Custo real | Substituição |
|--------|------------|--------------|
| Rolagem infinita em redes | 15-30 min/dia de atenção | Leitura de artigo salvo ou fechamento de janela |
| Cafeína após 16h | Sono prejudicado | Chá ou água |
| Multitarefa entre projetos | Context switching caro | Pomodoro estrito no projeto da vez |
| Perfeccionismo em código não crítico | Atraso em entrega | MVP funcional > bonito |
| Começar sem planejar o dia | Direção difusa | 5 min de revisão matinal |

## Padrões de produtividade

O que funciona (dados empíricos do vault):
- **Manhã:** melhor para aprendizado e leitura.
- **Início da tarde:** pico de produção de código.
- **Fim da tarde:** tarefas mecânicas e comunicação.
- **Noite:** criatividade difusa e revisão.
- **Sexta-feira:** ideal para fechar pendências e revisar.
- **Domingo:** planejamento da semana e autoconhecimento.

## Notas sobre energia e foco

| Estado | Sinal | Ação |
|--------|-------|------|
| ⚡ Alta energia | Foco sustentado, ideias fluindo | Aproveitar para blocos longos |
| 🔋 Média | Distraível mas funcional | Tarefas conhecidas, revisões |
| 🔋 Baixa | Sono e dispersão | Pausa, descanso ou atividade física leve |
| 🔴 Sobrecarga | Irritação, tédio, cansaço mental | Desconexão total — recomeçar amanhã |

## 📊 Habit Tracker Vivo

```dataviewjs
const HABITS = [
  "Acordei no horário planejado",
  "Revisão do dia feita",
  "Bloco de foco no projeto principal",
  "Movimento físico",
  "Telas desligadas"
];

const today = dv.date("today");
const since = today.minus({ days: 30 });
const pages = dv.pages("#diario")
  .where(p => {
    const d = dv.date(p.date);
    return d && d >= since && d <= today;
  })
  .sort(p => p.date, "asc");

if (pages.length === 0) {
  dv.paragraph("Nenhum diário encontrado nos últimos 30 dias.");
} else {
  const data = [];
  for (const p of pages) {
    const checks = p.file.tasks
      .filter(t => HABITS.some(h => t.text.includes(h)))
      .map(t => t.status === "x" ? 1 : 0);
    if (checks.length === 0) continue;
    const done = checks.reduce((a, b) => a + b, 0);
    data.push({ date: dv.date(p.date), done, total: checks.length, rate: done / checks.length });
  }

  let streak = 0;
  for (let i = data.length - 1; i >= 0; i--) {
    if (data[i].rate >= 0.8) streak++;
    else break;
  }
  dv.paragraph(`🔥 **Streak:** ${streak} dias seguidos (>80%)`);

  const weeks = {};
  for (const d of data) {
    const w = d.date.toFormat("yyyy-'W'WW");
    if (!weeks[w]) weeks[w] = { done: 0, total: 0, days: 0 };
    weeks[w].done += d.done;
    weeks[w].total += d.total;
    weeks[w].days++;
  }
  const weekRows = Object.entries(weeks).sort(([a], [b]) => a.localeCompare(b));
  dv.table(
    ["Semana", "Feitos", "Taxa", "Dias"],
    weekRows.length
      ? weekRows.map(([w, v]) => [
          w,
          `${v.done}/${v.total}`,
          (v.done / v.total * 100).toFixed(1) + "%",
          `${v.days}/7`
        ])
      : [["—", "—", "—", "—"]]
  );

  dv.paragraph("### Últimos dias");
  dv.table(
    ["Data", "Feitos", "%"],
    data.slice(-14).reverse().map(d => [
      d.date.toFormat("dd/MM"),
      `${d.done}/${d.total}`,
      (d.rate * 100).toFixed(0) + "%"
    ])
  );
}
```
