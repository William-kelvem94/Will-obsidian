## Como este vault processa leituras

1. **Descoberta** → Livro/artigo identificado → entrada nesta nota com status "🔍 Quero ler" ou "📖 Na lista".
2. **Leitura ativa** → Enquanto leio → capturas no [[Cerebro-Will|Cérebro Will]] com tags do livro → citações, reflexões, conexões com projetos.
3. **Conclusão** → Ao terminar → nota de resumo com link para esta página → status vira "✅ Lido".
4. **Processamento** → Insights relevantes viram tarefas ou decisões em [[Will-Pessoal/01-Identidade/Projetos/Projetos-Ativos|projetos ativos]].
5. **Reutilização** → No futuro → Jarvis consulta este banco de conhecimento para responder com base no que foi lido e processado.
6. **Revisão trimestral** → Quais leituras geraram mais impacto? O que foi esquecido e merece revisita?
