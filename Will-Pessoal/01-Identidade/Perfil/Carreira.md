# Carreira

## Timeline profissional

### 2009–2014 — Fundamentos
- Primeiros sites em HTML/CSS. Fóruns, blogs, sistemas simples em PHP.
- Descoberta de bancos de dados relacionais (MySQL). O poder de modelar dados mudou a forma de pensar.
- Projetos escolares que despertaram o gosto por resolver problemas com código.
- Aprendizado autodidata puro — documentação, fóruns, tentativa e erro sem orientação formal.
- **Entregável da época:** Sistemas de loophole, portais informativos, plugins de fórum.

### 2015–2018 — Fullstack emergente
- Início profissional como desenvolvedor web em agências e empresas de pequeno porte.
- Stack principal: PHP + jQuery + MySQL. Alguma experiência com C# (.NET) e Java (Android básico).
- Primeiros contatos com Python — inicialmente para scripts de automação de tarefas repetitivas.
- Projetos internos: sistemas de gestão de estoque, portais corporativos, CRUDs de alta complexidade.
- Descoberta de versionamento com Git — antes disso, era FTP e pastas com data no nome.
- **Entregável da época:** Sistemas web completos do zero ao deploy.

### 2019–2021 — Especialização em automação
- Python se torna linguagem principal. Adeus PHP como primeira opção.
- Mergulho em scraping (Scrapy, BeautifulSoup), ETL e pipelines de dados.
- Docker entra no fluxo — primeiro containerização, depois orquestração com Docker Compose.
- Deployments em nuvem: Digital Ocean, AWS Lightsail, VPS própria.
- Descoberta do ecossistema Javascript moderno: Node.js assíncrono, React para interfaces, TypeScript para sanidade.
- Projetos freelance e sistemas próprios começam a ganhar tração e gerar receita.
- **Entregável da época:** Pipelines de coleta de dados, dashboards, primeiros SaaS.

### 2022–2024 — Virada para IA local
- Descoberta do universo de Large Language Models e execução local — sem depender de API paga.
- Experimentos intensivos com Ollama, FAISS, embeddings, RAG, agentes.
- Criação do [[Will-Pessoal/01-Identidade/Projetos/Projetos-Ativos|PROJECT_JARVIS_5.0]] — assistente pessoal com memória e contexto persistente.
- Transição para SaaS: Auto-boletos (automação financeira) e Gestor Aluguel 2.0 (multi-tenant imobiliário).
- Infraestrutura própria amadurece: Traefik, Docker Compose, VPS com proxy reverso, monitoramento básico.
- **Entregável da época:** Assistentes com RAG, produtos SaaS multi-tenant, infraestrutura escalável.

### 2025–2026 — Consolidação
- Produtos SaaS em operação com usuários reais e receita recorrente.
- IA local integrada ao fluxo de trabalho pessoal — Jarvis ajuda a navegar o vault, responde perguntas, mantém contexto.
- [[Will-Pessoal/01-Identidade/Perfil/Skills|Skills consolidadas]] em IA, DevOps e produto. Transição de generalista para especialista com visão ampla.
- Construção ativa do ecossistema [[Will-Pessoal/03-Vida-Estilo/Conhecimento/Leituras|conhecimento ↔ código]] — o que aprendo vira código, o que codifico gera aprendizado.
- **Entregável da época:** Ecossistema integrado de produtos, conhecimento e ferramentas.

### Gerenciais e estratégicas
- Definir escopo com clareza — o que entra e o que fica de fora. Essencial para projetos solo.
- Validar rápido com MVPs funcionais. Funcionalidade mínima que resolve um problema real.
- Documentar decisões e aprendizados de forma reutilizável — o vault como memória institucional.
- Equilibrar dívida técnica com velocidade de entrega. Saber quando refatorar e quando seguir em frente.
- Precificação de produtos SaaS — descobrir o que o mercado aceita pagar.

## Áreas de interesse para crescimento

- **Arquitetura de agentes com memória de longo prazo** — O grande desafio do Jarvis. Como um agente lembra do que fez há semanas?
- **Fine-tuning de modelos pequenos (3B-8B parâmetros)** — Rodar em hardware modesto com qualidade aceitável.
- **Voz e visão como interface** — Microfone + câmera como canais de entrada naturais. Whisper + algum modelo de imagem.
- **Produto SaaS sustentável para o mercado brasileiro** — Do código ao cliente sem dependência de grandes plataformas.
- **Processamento de conhecimento pessoal** — O vault como banco de conhecimento ativo que o Jarvis consulta.
- **Arquiteturas event-driven** — Mensageria para desacoplar processos dentro dos produtos.

## Oportunidades identificadas no mercado

- **Ferramentas de produtividade com IA** — Mercado aquecido globalmente, ainda incipiente no Brasil.
- **IA local como nicho** — Poucos exploram execução local com qualidade. Diferencial competitivo.
- **Produto completo sozinho** — Experiência fullstack permite entregar do design ao deploy sem equipe.
- **Automação B2B** — Pequenas e médias empresas brasileiras precisam de automação barata. Pouca oferta de qualidade.
- **Conhecimento como produto** — O vault e o Jarvis podem evoluir para um produto de gestão de conhecimento pessoal.

## Lições aprendidas na carreira

- Projetos pessoais viram portfólio. Trate cada um com carinho — eles falam por você.
- Documentar enquanto constrói economiza meses depois. Uma nota de 5 minutos hoje evita 2 horas de debugging amanhã.
- O melhor framework é o que você já conhece bem. Novidade só vale se resolver um problema real que a atual não resolve.
- Dívida técnica paga com juros compostos. Refatorar cedo compensa exponencialmente.
- Networking real vale mais que 100 conexões no LinkedIn. Uma conversa honesta com outro dev ensina mais que qualquer tutorial.
- Saber dizer "não" para projetos e clientes é tão importante quanto saber dizer "sim". Escopo mal definido é a maior causa de fracasso.
- A carreira não é linear. Fases de baixa produtividade são normais. O importante é não parar.
- A melhor decisão de carreira foi investir em aprender IA local antes do hype. Antecipação paga dividendos.
