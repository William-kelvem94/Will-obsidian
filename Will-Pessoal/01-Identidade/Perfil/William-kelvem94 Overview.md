## Estilo de código

Princípios que norteiam a escrita no dia a dia:

1. **Legível primeiro, otimizado depois.** Código que não dá pra ler em 6 meses é código morto.
2. **Tipagem sempre que possível.** TypeScript e type hints em Python são padrão.
3. **Documentação mínima mas suficiente.** README no projeto, docstrings nas funções públicas.
4. **Testes nas bordas.** Critical paths cobertos; UI leve.
5. **Commits semânticos.** `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`.
6. **Containerizado desde o início.** Docker Compose para desenvolvimento e produção.
