# Objetivos do Vault de Projetos

Esta pasta contém a camada de objetivos e metas do vault.
Ela deve ser usada para alinhar visão, priorização e resultados esperados em um nível acima dos roadmaps individuais.

## O que pertence aqui
- Objetivos do vault e do portfólio de projetos.
- Metas trimestrais e de 90 dias.
- OKRs ou resultados-chave para as iniciativas principais.
- Conexões entre estratégia (`EstudosFocados`) e execução (`Privados`).

## Como usar
1. Defina objetivos claros para o próximo ciclo de 90 dias.
2. Relacione cada objetivo a pelo menos um projeto principal.
3. Use os resultados-chave como critérios de sucesso.
4. Atualize regularmente conforme as prioridades mudam.

## Estrutura recomendada
- `README.md` → visão geral dos objetivos do vault.
- `90-dias.md` → metas e entregáveis para o trimestre.
- `OKRs.md` → objetivos e resultados-chave mensuráveis.
