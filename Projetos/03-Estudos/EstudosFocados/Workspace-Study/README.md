# Workspace Study Hub

Este é o ponto de entrada para a investigação do vault, a análise de sua estrutura e a expansão do conhecimento técnico.

## Objetivo
- Centralizar a investigação do cofre e sua arquitetura de projetos.
- Registrar descobertas, lacunas e recomendações de estudo.
- Criar um espaço de estudo antes de partir para implementação.

## Principais trilhas de estudo
- **IA local**: voz, visão, RAG e modelos offline.
- **MCP e agentes**: workflows, agentes personalizados e integração com JARVIS.
- **DevOps**: deploy gratuito, infraestrutura local e operações do vault.
- **VS Code**: uso de Copilot, prompts, MCP e workflows de edição/validação.
- **Estrutura do vault**: papéis das pastas, hubs e conexões entre notas.

## Como usar
1. Leia a análise principal para entender o estado atual do vault.
2. Escolha uma trilha de estudo e abra a nota correspondente.
3. Adicione novas notas de pesquisa à pasta quando identificar temas novos.
4. Atualize `Projetos/EstudosFocados/README`, `skills/README` ou `Vault-Ops.md` quando algo for consolidado.
5. Use tags como `#workspace-study`, `#study-track`, `#gap`, `#next-step`.

## Uso recomendado
- Ao iniciar um novo projeto ou pesquisa, refira-se primeiro a `Workspace Structure Map`.
- Para decisões técnicas, abra `MCP and Agents Research` ou `DevOps and Infrastructure Research`.
- Para IA local, use `IA Local Research` como base de estudo.
- Para melhorar o fluxo no VS Code, use `VS Code and Workflow Research`.
