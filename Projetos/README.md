# Projetos GitHub Organizados por Linguagem

#projetos #hub

Esta pasta é o hub principal de projetos públicos e privados mapeados no vault.

## Estrutura Atual
```
Projetos/
├── Python/          ← Automatizador.md, TRADUTOR-WKP.md
├── PHP/             ← CRUD_VENDAS_WILL.md, CRUD_BASICO*.md
├── Java/            ← Atividade-01.md, Atividade-03.md
├── Outros/          ← DIA-DAS-MULHERES.md, Auto-boletos.md, Gestor Aluguel 2.0.md
├── Privados/        ← projetos clonados localmente com análise
├── Objetivos/       ← metas, OKRs e planejamento de 90 dias
├── EstudosFocados/  ← roadmaps e análises profundas
└── EstudosPesquisas/← recursos e pesquisa técnica
```

## Organização do Vault
- `Projetos/` → projetos públicos organizados por linguagem.
- `Projetos/Privados/` → clones locais de repos privados e análise de produto.
- `Projetos/EstudosFocados/` → notas de roadmap, diário de bordo e visão estratégica.
- `Projetos/EstudosPesquisas/` → recursos gratuitos para AI local, Docker, Next.js, visão e voz.
- [[Projetos/01-Ativos/Plano-de-Acao|Projetos/Plano-de-Acao.md]] → checklist operacional e prioridades.
- [[Projetos/04-Master-Plan/Organizacao-Completa|Projetos/Organizacao-Completa.md]] → visão mestre da estrutura do vault.
- [[Vault-Ops|Manutenção do Vault]] — scripts e checklist para manter o cofre alinhado.
- [[Projetos/04-Master-Plan/GitHub-Completo|Projetos/GitHub-Completo.md]] → captura geral dos 67 repositórios do GitHub.
