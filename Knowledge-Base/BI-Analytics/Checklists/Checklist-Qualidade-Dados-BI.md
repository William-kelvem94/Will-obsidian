# CHECKLIST QUALIDADE DE DADOS & INCIDENT HANDLING – BI

## 1. Qualidade de Dados
- [ ] Pipelines monitoram schema, campo obrigatório, tipagem
- [ ] Alertas para anomalias estatísticas (outliers, missing)
- [ ] Logging detalhado por ingest/ciclo
- [ ] Owners/gestores definidos por área
- [ ] Incidentes registrados em atomic notes
- [ ] Triggers para auditoria manual após cada falha
- [ ] Output salvo em padrão YAML/JSON

## 2. Incident Handling ativo
- [ ] Documentação padronizada incidentes, causas e métricas
- [ ] Registro automático de lessons learned
- [ ] Review semanal de todos incidentes BI
- [ ] Relatório para time board (cópia via Obsidian)
- [ ] Dashboard integrado a chain-of-custody
