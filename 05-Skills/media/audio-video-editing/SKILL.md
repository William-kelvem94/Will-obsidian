# Audio & Video Editing Skill

Use this skill when scripting video renderers, editing screencasts/podcasts, or defining guidelines for post-production.

## Core Concepts

### Video Editing
- **Aspect Ratios**: 16:9 (Landscape), 9:16 (Vertical Shorts/TikTok), 1:1 (Square).
- **Color Grading**: Working with LOG profiles, applying LUTs, color correction vs. color grading.
- **Codecs**: H.264/H.265 (Delivery), ProRes/DNxHR (Editing/Intermediate).

### Audio Production
- **Gain Staging**: Ensuring signals are balanced without clipping.
- **Effects Chain**: Noise Gate -> Equalizer (EQ) -> Compressor -> Limiter.
- **Loudness Standards**: Targeting -14 LUFS for streaming platforms (Spotify, YouTube).
- **Automated Pipelines**: Using Python (e.g., MoviePy, Pydub) to programmatically edit clips, sync tracks, or burn subtitles.
