# LLMOps & Fine-Tuning Skill

Use this skill when designing data ingestion pipelines for vector databases, fine-tuning open-source models, or optimizing inference systems.

## Core Capabilities

- **Fine-Tuning**: Formulating training datasets, utilizing LoRA/QLoRA adapters, and deploying models using frameworks like Hugging Face, Axolotl, or Unsloth.
- **LLMOps**: Managing model lifecycles, evaluating hallucination rates, logging prompts/responses, and configuring guardrails (e.g., NeMo Guardrails).
- **Local Inference**: Hosting open models (Llama 3, Mistral, Qwen) using Ollama, Llama.cpp, vLLM, or Hugging Face TGI.
- **Advanced RAG**: Implementing hybrid search, semantic reranking (e.g., Cohere/BGE), metadata pre-filtering, and query expansion.
