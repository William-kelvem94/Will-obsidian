# Browser Automation

## When to use

- inspect web apps;
- gather structured information;
- verify flows end to end;
- repeat UI tasks safely;
- support research with live sources.

## Guardrails

- use explicit targets;
- prefer read-only by default;
- avoid brittle selectors when possible;
- capture screenshots for important checks;
- stop if the UI state is ambiguous.
