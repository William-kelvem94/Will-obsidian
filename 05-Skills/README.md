## Regra de skill

Uma skill deve ter:

- objetivo;
- quando usar;
- prerequisitos;
- exemplos;
- limitacoes;
- checklist;
- links para projetos onde foi aplicada.

## Escala de crescimento

Quando um dominio crescer rapido, use um `INDEX` auxiliar por subpasta sem alterar o indice principal ate o mapa estabilizar.
