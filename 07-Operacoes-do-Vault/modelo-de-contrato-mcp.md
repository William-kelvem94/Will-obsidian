# Modelo de Contrato MCP

## Campos minimos

- nome;
- versao;
- objetivo;
- transporte;
- autenticacao;
- tools expostas;
- leitura permitida;
- escrita permitida;
- allowlist/denylist;
- logs;
- testes;
- modo de falha;
- responsavel.

## Decisoes obrigatorias

- o que pode escrever;
- onde pode escrever;
- quais dados nunca entram;
- como reverter uma mudanca;
- como auditar uso.
