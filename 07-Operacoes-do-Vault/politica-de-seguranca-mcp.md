# Politica de Seguranca MCP

## Regras basicas

- escrita so com escopo limitado;
- credenciais nunca em texto claro;
- dados sensiveis isolados por design;
- integracoes externas com logs;
- cada tool com rollback ou plano de falha;
- mudancas grandes passam por revisao.
