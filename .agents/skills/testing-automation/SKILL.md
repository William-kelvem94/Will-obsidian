# Testing Automation & CI/CD Skill

Use this skill when configuring GitHub Actions, GitLab CI, Jenkins, or writing load/stress tests (e.g., using Locust, k6).

## Key Objectives

- **CI/CD Integration**: Run automated test suites (Unit, Integration, Linting, Security scanning) on pull requests and commits.
- **Stress & Load Testing**: Simulating high traffic scenarios to identify bottlenecks, resource leaks, and autoscaling thresholds.
- **Continuous Deployment Gates**: Enforce code coverage metrics, performance benchmarks, and green-build constraints before production deployment.

## Automation Tools

- **CI Engines**: GitHub Actions, GitLab CI/CD, CircleCI.
- **Load Testing**:
  - `k6` (JavaScript-based scriptable load generator).
  - `Locust` (Python-based developer-friendly load tester).
  - `Apache JMeter` (Legacy XML/GUI-based performance suite).
