# Avaliação de Respostas de IA

Nem toda resposta bonita é correta. Avaliar IA exige separar fluidez, utilidade e verdade.

## Critérios principais

| Critério | Pergunta |
|---|---|
| precisão | a resposta está factual? |
| completude | cobriu o que foi pedido? |
| evidência | mostra fonte, contexto ou justificativa? |
| utilidade | ajuda a agir melhor? |
| segurança | evita riscos desnecessários? |
| honestidade | diz quando não sabe? |
| alinhamento | respeita objetivo, tom e restrições? |

## Sinais de boa resposta

- responde diretamente;
- declara incertezas;
- separa fato de opinião;
- usa exemplos úteis;
- não inventa fonte;
- não exagera confiança;
- oferece próximo passo claro;
- adapta profundidade ao pedido.

## Sinais de resposta fraca

- parece genérica;
- foge da pergunta;
- usa termos vagos;
- não mostra critérios;
- ignora restrições;
- cria dados não fornecidos;
- dá solução grande para problema pequeno;
- responde com certeza em tema incerto.

## Checklist de revisão

- [ ] A resposta resolve o pedido principal?
- [ ] Há alguma afirmação que precisaria de fonte?
- [ ] Algum detalhe foi inventado?
- [ ] A resposta diferencia hipótese de fato?
- [ ] O formato ficou útil?
- [ ] Há risco se o usuário seguir a orientação?
- [ ] Existe passo prático final?

## Uso com RAG

Quando a IA usa o vault, avaliar também:

- se consultou a nota correta;
- se respeitou o contexto mais recente;
- se não misturou áreas indevidas;
- se citou ou mencionou notas relevantes;
- se não ignorou decisões registradas.

## Pontuação simples

| Nota | Significado |
|---|---|
| 1 | errada ou perigosa |
| 2 | incompleta ou vaga |
| 3 | aceitável |
| 4 | boa e útil |
| 5 | precisa, útil e bem justificada |
