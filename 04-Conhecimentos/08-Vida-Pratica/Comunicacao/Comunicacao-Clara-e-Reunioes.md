# Comunicação Clara e Reuniões

Comunicação clara reduz retrabalho. Reunião boa gera decisão, alinhamento ou desbloqueio. Se não gera nada disso, provavelmente precisa virar mensagem ou documento.

## Comunicação objetiva

Uma boa mensagem responde:

- qual é o contexto?
- qual é o problema?
- o que já foi tentado?
- qual decisão é necessária?
- qual é o prazo?
- quem precisa agir?

## Estrutura curta

```md
Contexto:
Problema:
Impacto:
Tentativas:
Pedido:
Prazo:
```

## Reunião produtiva

Uma reunião boa tem:

- objetivo claro;
- pauta curta;
- participantes necessários;
- decisões registradas;
- responsáveis definidos;
- próximos passos;
- tempo limitado.

## Tipos de reunião

| Tipo | Objetivo |
|---|---|
| alinhamento | garantir entendimento comum |
| decisão | escolher caminho |
| diagnóstico | entender problema |
| retrospectiva | aprender com o que aconteceu |
| planejamento | definir prioridades e ações |

## Ata mínima

```md
# Reunião - tema

## Data

## Participantes

## Contexto

## Decisões

## Pendências

## Responsáveis

## Próximos passos
```

## Erros comuns

- reunião sem pauta;
- sair sem responsável;
- discutir tudo e decidir nada;
- não registrar combinado;
- misturar problema técnico com conflito pessoal;
- deixar expectativa implícita;
- falar muito sem confirmar entendimento.

## Checklist

- [ ] A reunião precisa existir?
- [ ] O objetivo está claro?
- [ ] Há decisão esperada?
- [ ] Quem precisa participar?
- [ ] As pendências foram registradas?
- [ ] Existe dono para cada ação?
