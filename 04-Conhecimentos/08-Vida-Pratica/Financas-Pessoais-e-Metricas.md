# Finanças Pessoais e Métricas

Finanças pessoais são uma forma de gestão de energia futura. Organizar dinheiro reduz improviso e aumenta liberdade de decisão.

## Categorias básicas

| Categoria | Exemplos |
|---|---|
| receita fixa | salário, ajuda mensal |
| receita variável | bônus, freelas, app |
| despesa fixa | parcela, internet, assinatura |
| despesa variável | combustível, alimentação, lazer |
| dívida | cartão, financiamento, empréstimo |
| reserva | emergência e segurança |
| investimento | crescimento de patrimônio |

## Métricas úteis

| Métrica | Fórmula simples |
|---|---|
| saldo mensal | receitas - despesas |
| taxa de poupança | valor guardado / receita |
| custo fixo | soma das despesas recorrentes |
| margem livre | receita - custos obrigatórios |
| dívida mensal | parcelas / receita |
| reserva em meses | reserva / custo mensal |

## Regra de clareza

Antes de decidir comprar algo, responder:

- é necessidade ou desejo?
- cabe no mês sem sufocar?
- aumenta dívida fixa?
- prejudica reserva?
- resolve um problema real?
- há alternativa mais barata?

## Reserva de emergência

Reserva é proteção contra imprevisto. O alvo depende de estabilidade de renda, responsabilidades e risco.

Passos:

1. Mapear custo mensal essencial.
2. Guardar primeiro alvo pequeno.
3. Aumentar para meses de segurança.
4. Evitar usar para desejo comum.
5. Repor quando usar.

## Erros comuns

- olhar só parcela e não custo total;
- ignorar pequenos gastos recorrentes;
- misturar dinheiro de meta com dinheiro livre;
- usar cartão como extensão de renda;
- não registrar gastos variáveis;
- decidir em pico emocional.

## Checklist mensal

- [ ] Receita total registrada?
- [ ] Despesas fixas atualizadas?
- [ ] Cartão revisado?
- [ ] Reserva recebeu aporte?
- [ ] Dívidas estão sob controle?
- [ ] Existe meta para o próximo mês?
- [ ] Algum gasto precisa ser cortado ou renegociado?
