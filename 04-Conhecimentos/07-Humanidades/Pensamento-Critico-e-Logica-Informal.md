# Pensamento Crítico e Lógica Informal

Pensamento crítico é a capacidade de avaliar afirmações, argumentos e decisões com clareza. Não é ser cético de tudo, é saber separar evidência, interpretação e conclusão.

## Estrutura de argumento

| Parte | Pergunta |
|---|---|
| afirmação | o que está sendo dito? |
| premissa | por que isso seria verdade? |
| evidência | qual dado sustenta? |
| inferência | como chegou à conclusão? |
| conclusão | o que se quer provar? |

## Perguntas críticas

- Isso é fato, opinião ou interpretação?
- Qual evidência apoia?
- Existe outra explicação?
- O argumento depende de uma premissa escondida?
- O exemplo representa o todo?
- Há conflito de interesse?
- O que mudaria essa conclusão?

## Falhas comuns

| Falha | Descrição |
|---|---|
| falso dilema | fingir que só existem duas opções |
| generalização apressada | concluir com pouca amostra |
| ataque pessoal | atacar pessoa em vez do argumento |
| apelo à emoção | emoção substitui evidência |
| causa falsa | confundir sequência com causa |
| espantalho | distorcer argumento do outro |
| confirmação | buscar só o que confirma crença |

## Como usar com IA

Ao avaliar resposta de IA:

- identificar afirmações fortes;
- pedir evidência;
- separar certeza de hipótese;
- checar se faltam alternativas;
- procurar simplificações exageradas;
- verificar se a resposta respeita o contexto.

## Checklist

- [ ] A conclusão segue das premissas?
- [ ] A evidência é suficiente?
- [ ] Há alternativa plausível?
- [ ] Alguma palavra está ambígua?
- [ ] Existe viés emocional ou interesse?
- [ ] A decisão depende de dado ausente?

## Resumo para IA

Pensamento crítico exige separar fato, evidência, interpretação e conclusão. Ao analisar texto, procurar premissas ocultas, alternativas e grau de confiança.
