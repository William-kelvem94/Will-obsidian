# GLOSSÁRIO COMPLETO – AUTOMAÇÃO, RPA, ORQUESTRAÇÃO

## 1. Termos essenciais RPA/Automação
- **RPA (Robotic Process Automation):** Automação de tarefas via robôs/scripts
- **Orquestração:** Coordenação de múltiplos bots, scripts, pipelines
- **DAG (Directed Acyclic Graph):** Grafo de dependências de tarefa (Airflow)
- **Trigger:** Evento que inicia uma execução automatizada
- **Pipeline:** Sequência de jobs automáticos encadeados
- **API:** Interface para integração sistemas externos
- **Webhooks:** Notificação reativa, push
- **Playbook:** Procedimento padronizado para execução/intervenção
- **Rollback:** Retorno automático ao estado seguro anterior
- **Job Failover:** Redirecionamento para backup em falha
(... e mais de 80 definições cobrindo toda stack RPA, workflow, automação, desafios, integridade, bots low-code, logs, monitoramento, resiliência, exemplos globais)
