# RESPOSTA A INCIDENTE — MULTIJURISDIÇÃO

## 1. Caso comparado (Brasil x Europa)
- Evento: ataque ransomware com exposure de dados centralizados BR/EUROPA
- BRASIL: notificação ANPD, titulares, plano público de correção em até 48h, backup chain-of-custody, revisão de scripts
- EUROPA (GDPR): notificação prévia à DPA, template detalhado, reporte a board, público e clientes (RGPD, Art. 33/34)

## 2. Lições e decisões práticas
- Necessidade de script automatizado para identificar qual jurisdição impactada
- Logs e outputs técnicos unificados, branch revision control para cada incidente
- Lessons learned obrigatória documentada no hub
- Atendimento de ambos templates e deadlines
