## Lacunas prioritarias

| Dominio | Gap atual | Proximo lote recomendado |
|---|---|---|
| IA e Agentes | muito material disperso, precisa consolidacao | arquitetura de memoria, evals, prompt ops, agent safety |
| Engenharia de Software | forte, mas pouco mapeado por subtema | APIs, arquitetura, testes, release, observabilidade |
| Dados e Analytics | base boa, precisa mais massa aplicada | metricas, dashboards, modelagem, notebooks, experimentos |
| Seguranca e Redes | precisa mais casos e runbooks | threat models, deteccao, hardening, incident response |
| Produto/UX | subcobertura relativa | discovery, prototipacao, pesquisa, estrategia |
| Estudos e Aprendizagem | util, mas pouco granular | revisao espacada, memoria, flashcards, metodo de estudo |
| Humanidades | mais conceito que analise | filosofia, historia, psicologia, sociologia |
| Vida Pratica | precisa virar sistema operacional pessoal | rotina, finanças, saude, produtividade, habitos |

## Formato recomendado para novos lotes

1. Uma nota de sintese.
2. Tres a cinco conceitos reutilizaveis.
3. Dois a cinco entities ligadas.
4. Uma tabela ou matriz de comparação.
5. Uma lista de open questions.
6. Um bloco de proximo passo para future agents.

## Regra de qualidade

Um novo bloco de conhecimento geral so entra se:

- tiver motivo claro;
- responder a uma pergunta futura;
- puder ser ligado ao mapa do dominio;
- evitar duplicacao vazia;
- ajudar navegacao ou decisao.
