# Mapa Mestre de Conhecimentos Gerais

## Objetivo

Converter os dominios gerais do vault em uma malha de conhecimento reutilizavel, conectada e expansivel, evitando que os temas fiquem apenas como pastas soltas.

## Dominios principais

| Dominio | Papel | Tipo de massa a produzir | Prioridade |
|---|---|---|---|
| IA e Agentes | raciocinio, arquitetura e orquestracao | conceitos, playbooks, comparativos, failure modes | alta |
| Engenharia de Software | praticas, padroes e execucao | cheat sheets, ADRs, checklists, casos | alta |
| Dados e Analytics | metricas, dashboards e analise | notebooks, scorecards, rubricas, datasets | alta |
| Seguranca e Redes | defesa e confianca | guias, threat models, incidentes, checklists | alta |

## Tipos de artefato para massa

1. `sources` para fontes base e referenciais.
2. `concepts` para ideias reutilizaveis.
3. `entities` para autores, teorias, sistemas, instituicoes e obras.
4. `summaries` para visoes de dominio.
5. `analysis` para comparacao, gaps e decisao.

## Regra de expansao

Cada dominio deve gerar:

- um hub ou index claro;
- um mapa de lacunas;
- uma trilha de fontes;
- um conjunto de conceitos centrais;
- pelo menos uma analise por tema forte;
- um conjunto de notas sinteticas ligadas entre si.
