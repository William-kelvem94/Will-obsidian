# Matemática Aplicada à Computação

Matemática aplicada à computação ajuda a entender algoritmos, dados, IA, otimização, gráficos, criptografia e desempenho.

## Áreas importantes

| Área | Aplicação |
|---|---|
| lógica | condições, provas, algoritmos |
| álgebra | manipulação simbólica e estruturas |
| álgebra linear | IA, gráficos, vetores, embeddings |
| cálculo | otimização e modelos contínuos |
| probabilidade | incerteza e previsão |
| estatística | análise de dados e decisão |
| grafos | redes, rotas, dependências |
| matemática discreta | computação em geral |

## Álgebra linear

Conceitos úteis:

- vetor;
- matriz;
- produto escalar;
- distância;
- similaridade;
- espaço vetorial;
- transformação linear.

Aplicações:

- embeddings;
- busca semântica;
- modelos de IA;
- gráficos 2D e 3D;
- recomendação.

## Probabilidade e estatística

Útil para:

- avaliar dados;
- medir risco;
- interpretar métricas;
- testar hipóteses;
- entender incerteza;
- analisar desempenho.

## Grafos

Grafos modelam relações.

Exemplos:

- links entre notas do Obsidian;
- dependências de software;
- redes sociais;
- rotas;
- chamadas entre serviços.

## Matemática para IA

IA moderna usa:

- vetores;
- matrizes;
- otimização;
- probabilidade;
- estatística;
- funções de perda;
- distância e similaridade.

## Como estudar

1. Aprender conceito mínimo.
2. Ver aplicação prática.
3. Implementar exemplo simples.
4. Resolver exercícios.
5. Criar nota com intuição e fórmula.
6. Revisar depois.

## Erros comuns

- estudar fórmula sem aplicação;
- fugir de exercícios;
- decorar sem entender;
- achar que precisa dominar tudo antes de programar;
- não conectar matemática com projetos reais.
