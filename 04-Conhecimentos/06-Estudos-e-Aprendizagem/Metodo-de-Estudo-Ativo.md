# Método de Estudo Ativo

Estudar ativamente é transformar informação em habilidade. Não basta ler, destacar ou assistir aula. O cérebro precisa recuperar, explicar, aplicar e revisar.

## Ciclo de aprendizagem

1. Capturar o tema.
2. Entender o mapa geral.
3. Quebrar em conceitos menores.
4. Explicar com as próprias palavras.
5. Resolver exercícios ou criar algo.
6. Revisar depois de um intervalo.
7. Ensinar ou documentar.

## Técnicas essenciais

### 1. Active recall

Tentar lembrar antes de consultar. Isso fortalece memória.

Perguntas:

- O que é isso?
- Para que serve?
- Qual problema resolve?
- Quando usar?
- Quando não usar?
- Qual exemplo simples?

### 2. Revisão espaçada

Revisar em intervalos:

- mesmo dia;
- 1 dia depois;
- 3 dias depois;
- 7 dias depois;
- 14 dias depois;
- 30 dias depois.

### 3. Técnica Feynman

Explicar como se fosse para alguém inteligente, mas iniciante. Se travar, há lacuna.

### 4. Projeto pequeno

Toda tecnologia aprendida deve virar um mini-projeto. Exemplo: estudar API e criar um CRUD simples.

## Template de estudo

```md
# Tema

## O que é

## Para que serve

## Conceitos fundamentais

## Exemplo simples

## Erros comuns

## Exercícios

## Perguntas de revisão

## Próximo passo
```

## Como estudar tecnologia

1. Ler visão geral.
2. Rodar exemplo mínimo.
3. Quebrar de propósito.
4. Corrigir erro.
5. Criar algo pequeno.
6. Documentar aprendizado.
7. Transformar em nota no vault.

## Erros comuns

- estudar só consumindo conteúdo;
- trocar de curso sem praticar;
- buscar ferramenta perfeita;
- evitar exercícios difíceis;
- não revisar;
- não registrar decisões;
- confundir familiaridade com domínio.

## Métrica de domínio

| Nível | Sinal |
|---|---|
| 1 | reconhece o tema |
| 2 | explica o básico |
| 3 | usa com consulta |
| 4 | resolve problema real |
| 5 | ensina e adapta |

## Perguntas de revisão

- Qual é a ideia principal?
- Qual problema isso resolve?
- Quais são os 3 conceitos centrais?
- Qual erro iniciante mais comum?
- Como aplicar em um projeto real?
- O que ainda não está claro?
