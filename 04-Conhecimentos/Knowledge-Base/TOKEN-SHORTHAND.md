## 📝 7. Regras de Uso

1. **Primeira ocorrência**: abreviação entre parênteses na primeira menção
   - Ex: "O sistema de Retrieval Augmented Generation (RAG) foi configurado..."
   - Após definido, usar apenas a abreviação

2. **Contexto claro**: usar apenas quando o significado for óbvio no contexto

3. **Evitar ambiguidade**: `proc` pode ser process ou procedure → desambiguar no contexto

4. **Densidade vs legibilidade**: compressão > 50% é perda de legibilidade para humanos

5. **Consistência**: SEMPRE usar a mesma abreviação para o mesmo termo

6. **Shorthand em schemas**: Em YAML/JSON, sempre usar shorthand para chaves
