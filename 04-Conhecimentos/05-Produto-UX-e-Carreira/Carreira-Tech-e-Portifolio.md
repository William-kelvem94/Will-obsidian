# Carreira Tech e Portfólio

Carreira em tecnologia não depende só de saber programar. Também exige comunicar valor, registrar entregas, resolver problemas reais e mostrar evolução.

## Pilares

| Pilar | Pergunta |
|---|---|
| habilidade técnica | o que sabe construir? |
| resolução de problema | que dor resolve? |
| comunicação | consegue explicar? |
| portfólio | existe prova do trabalho? |
| consistência | evolui ao longo do tempo? |
| colaboração | trabalha bem com outras áreas? |

## Portfólio forte

Um bom portfólio mostra:

- problema resolvido;
- contexto;
- stack usada;
- decisões técnicas;
- desafios;
- resultado;
- prints ou demo;
- README claro;
- próximos passos.

## Currículo técnico

Currículo bom não lista tarefas soltas. Ele mostra impacto.

Formato útil:

- verbo de ação;
- problema;
- tecnologia;
- resultado;
- escala quando possível.

Exemplo conceitual:

> Automatizei processo interno usando Python e API, reduzindo retrabalho manual e melhorando rastreabilidade.

## Como registrar conquistas

Criar uma nota por entrega importante com:

- data;
- problema;
- ação;
- resultado;
- evidência;
- aprendizado;
- como isso pode virar currículo.

## Erros comuns

- esconder projetos porque não estão perfeitos;
- não documentar resultados;
- subestimar trabalho de suporte e operação;
- falar só de ferramenta, não de problema;
- deixar GitHub sem README;
- não transformar experiência real em narrativa profissional.

## Checklist de projeto para portfólio

- [ ] Tem README?
- [ ] Explica problema?
- [ ] Mostra stack?
- [ ] Tem instrução para rodar?
- [ ] Tem prints ou descrição de uso?
- [ ] Tem decisões técnicas?
- [ ] Tem próximos passos?
