# Shell Scripting e Automação

Esta nota registra princípios para rotinas de terminal em Windows e Linux.

## Princípios

- Definir objetivo antes de executar.
- Confirmar shell alvo.
- Preferir leitura antes de mudança.
- Trabalhar com escopo pequeno.
- Registrar saída relevante.
- Validar resultado.
- Documentar riscos.
