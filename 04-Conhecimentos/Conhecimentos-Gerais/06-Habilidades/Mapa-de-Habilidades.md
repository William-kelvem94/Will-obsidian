# Mapa de Habilidades

Este mapa organiza habilidades úteis para estudos, projetos, trabalho e sistemas de IA. Ele serve como guia para evolução contínua.

## Categorias principais

1. IA e automação.
2. Engenharia de software.
3. Infraestrutura e DevOps.
4. Dados e documentação.
5. Produto e UX.
6. Comunicação técnica.
7. Gestão pessoal e decisão.

## IA e automação

| Habilidade | Nível desejado | Aplicação |
|---|---|---|
| prompt engineering | avançado | melhorar uso de IA |
| RAG | intermediário/avançado | memória do JARVIS |
| agentes | intermediário | automações e workflows |
| embeddings | intermediário | busca semântica |
| avaliação de respostas | avançado | reduzir erro e alucinação |

## Engenharia de software

| Habilidade | Aplicação |

## Comunicação técnica

Habilidades importantes:

- explicar problemas;
- escrever documentação;
- registrar decisões;
- traduzir tecnologia para negócio;
- conduzir reuniões;
- transformar conversa em plano de ação.

## Gestão pessoal

Habilidades importantes:

- priorização;
- revisão semanal;
- controle de energia;
- organização de projetos;
- consistência;
- saber pausar;
- reduzir dispersão.

## Níveis de domínio

| Nível | Descrição |
|---|---|
| 1 | conhece o termo |
| 2 | entende conceito básico |
| 3 | aplica com consulta |
| 4 | resolve problema real |
| 5 | ensina e adapta |

## Como evoluir uma habilidade

1. Definir objetivo prático.
2. Estudar base mínima.
3. Criar exercício.
4. Aplicar em projeto real.
5. Documentar no Obsidian.
6. Revisar depois.
7. Ensinar ou transformar em playbook.
