# WORKFLOW COMPLETO – SAÚDE SUPLEMENTAR AUTOMATIZADA

## 1. Objetivo
Automação de processos regulatórios e BI em operadora de saúde (scripts Python e notebooks, integração RPA/PowerBI/CI/CD).

## 2. Etapas-chave
- Coleta automática de planilhas via robots/agentes
- Extração de campos regulatórios e de resultado
- Validação compliance — templates YAML/JSON/GSheets
- Atualização automática do dashboard BI
- Notificação via chat/email para gestores/owners
- Logs de execução com chain-of-custody

## 3. Métricas de sucesso
- % tempo economizado por pipeline
- Ocorrência de inconsistências na base
- Número de notificações geradas
- Tempo resposta incidentes/regulação

## 4. Lessons learned
- Incidentes core logados via atomic notes
- Melhorias semanais a cada rodada do fluxo
- Templates e outputs prontos para expansão/demais operadoras
