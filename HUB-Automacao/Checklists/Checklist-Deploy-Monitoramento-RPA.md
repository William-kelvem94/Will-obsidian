# CHECKLIST – DEPLOY, MONITORAMENTO E CONTINGÊNCIA RPA

## 1. Antes do deploy
- [ ] Jobs/Bots autenticados, segredos revisados
- [ ] Testes de rollback e recovery ok
- [ ] Logs ativados, outputs salvos chain-of-custody
- [ ] Owners/gestores definidos por etapa
- [ ] Checklist específico compliance (financeiro, saúde, RH)
- [ ] Scripts backup validados (restore)

## 2. Monitoramento pipeline
- [ ] Alertas e triggers em tempo real
- [ ] Logs e métricas centralizados
- [ ] Falhas registradas em atomic notes obrigatoriamente
- [ ] Output/sucesso salvo para BI

## 3. Contingência e lessons learned
- [ ] Testes de caos engineering realizados
- [ ] Rolagem automática jobs críticos
- [ ] Documentação de incidente preenchida imediatamente

**Checklist atualizada/melhorada a cada ciclo via lessons learned (ver atomic notes).**
