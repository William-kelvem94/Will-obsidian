# Metadata Hygiene

Metadata hygiene keeps the knowledge graph machine-readable and maintainable.

## Practices

- use stable titles;
- keep tags controlled;
- update dates when meaning changes;
- avoid duplicate concepts with different names;
- keep links explicit and durable.
