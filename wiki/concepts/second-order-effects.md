# Second Order Effects

Decisions should be checked beyond the immediate outcome. A local gain can create a later cost.

## Examples

- more automation can create more maintenance;
- more content can create more retrieval burden;
- more access can create more risk;
- more speed can reduce quality if guardrails are weak.
