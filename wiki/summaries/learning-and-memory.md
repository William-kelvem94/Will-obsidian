# Learning and Memory

## Core idea

Learning compounds when attention, repetition, and retrieval are designed as a system.

## Practical layers

- episodic memory captures events;
- semantic memory stores facts and models;
- procedural memory stores repeatable actions;
- reflection converts experience into reusable structure.

## High-yield practices

- spaced repetition;
- active recall;
- interleaving;
- error logs;
- study notes with examples;
- regular synthesis passes.
