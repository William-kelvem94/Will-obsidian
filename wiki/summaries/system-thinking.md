# System Thinking

## Core pattern

Systems are shaped by:

- feedback loops;
- delays;
- constraints;
- local incentives;
- accumulation;
- emergence.

## What the vault should learn from this

- every note has neighbors;
- every tool has side effects;
- every process becomes a loop;
- every loop should be observable.
