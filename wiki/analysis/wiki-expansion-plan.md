# Wiki Expansion Plan

## Batch strategy

1. create source pages for stable inputs;
2. derive concept pages from repeated mechanisms;
3. create entity pages for important names;
4. write summary pages per domain;
5. add analysis pages for gaps and decisions;
6. update index and logs.

## Quality gate

- no orphaned note if avoidable;
- no duplicate concept without reason;
- every note should be linkable;
- every note should have a maintenance path.
