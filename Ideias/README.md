# IDEIAS / README

## Onboarding para painéis e automações massivas

Este diretório centraliza toda a expansão do seu vault baseada no super-brainstorm de 2026-05-19, incluindo scripts Python, painéis DataviewJS e arquivos de controle/backlog para cada ideia inovadora.

### Como usar

1. **Scripts:**
   - Todos os scripts estão em `.scripts/` e podem ser rodados manualmente (ou automatizar via Task Scheduler). Eles geram arquivos `.json` em `dashboards/`.
2. **Dashboards:**
   - Cada painel pode ser copiado/colado dos arquivos Ideias/(ideia).md em algum dashboard Obsidian.
   - O bloco DataviewJS do arquivo exibe os dados extraídos pelo script correspondente.
3. **Documentação:**
   - Use `Backlog-Desenvolvimento.md` e `Evolucao-de-Ideias.md` para acompanhar andamento, atualizar status e documentar melhorias.

### Integração rápida
- Copie o bloco javascript do `Ideias/<nome>.md` para seu dashboard (página ou note).
- Mantenha os scripts rodando (manual, plugin, ou agendador externo).
- Ajuste paths caso tenha estrutura única.

### FAQ e Expansão
- Quer nova ideia? Adicione no `Evolucao-de-Ideias.md` e inicie backlog.
- Precisa evoluir script, criar mais widgets? Inspire-se nos exemplos e evolua!
- Tem dúvida ou erro? Veja exemplos, compare paths e scripts, acione histórico.

Executando todos os painéis do brainstorm, seu second brain ganha monitoramento subjetivo, ciclo de revisão, insights automáticos, networking ativo, análise de tendências, coaching anti-procrastinação, conexões inéditas, pico produtivo e simulação de cenários. Tudo modular e plug-and-play ❤️
