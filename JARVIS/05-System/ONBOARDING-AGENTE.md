# 🤖 Como habitar este vault (para qualquer IA)

1. Leia `JARVIS/README.md` — protocolo de carregamento.
2. Consulte `Graph-Legenda.md` para entender as cores e tags.
3. Use os comandos MCP documentados em `Comandos-JARVIS.md`.
4. Para buscas semânticas, siga `RAG-Local-Guide.md`.
5. Templates estão em `Templates/` — use `Template Base.md` para novas notas.
6. Antes de modificar qualquer arquivo, verifique as diretrizes em `Conhecimento-Geral/COMO-CONTRIBUIR.md`.
7. Rode `vault_cleanup.py --check-only` antes de propor mudanças.
