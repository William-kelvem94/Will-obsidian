# Inbox

Esta pasta é a entrada temporária do vault.

## Uso

Coloque aqui conteúdos que ainda precisam ser classificados, como:

- ideias soltas;
- capturas rápidas;
- rascunhos;
- anotações sem destino;
- materiais para triagem.

## Regra

Nada deve morar aqui para sempre. Conteúdo útil deve virar conhecimento, projeto, memória, template ou arquivo.
