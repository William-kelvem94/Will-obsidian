# Arquivo

Esta pasta deve guardar conteúdos preservados, mas fora do fluxo ativo.

## Usar para

- notas antigas;
- duplicidades preservadas;
- versões legadas;
- materiais sem uso atual;
- conteúdos que não devem ser apagados.

## Regra

Arquivar não é apagar. Todo conteúdo movido para cá deve manter contexto mínimo sobre por que foi arquivado.
