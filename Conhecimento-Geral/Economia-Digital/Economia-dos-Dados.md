# Economia dos Dados

## Definição

A economia dos dados trata o dado como ativo econômico, considerando valor, propriedade, governança e mercados de dados.

## Contexto Histórico/Filosófico

O crescimento de plataformas digitais transformou dados em recurso central para decisão, personalização e vantagem competitiva.

## Aplicações Práticas (para IA)

Dados são a matéria-prima de modelos inteligentes. Data trusts e soberania de dados informam estratégias de governança, privacidade e uso ético em produtos de IA.
