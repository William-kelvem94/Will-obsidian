# Álgebra Linear Essencial

## Definição

Álgebra linear estuda vetores, matrizes, transformações lineares e decomposições que descrevem estruturas de espaço e operações em dados.

## Contexto Histórico/Filosófico

A álgebra linear evoluiu como linguagem matemática para resolver sistemas de equações lineares e hoje é a base para transformação de dados, projeções e embedding spaces.

## Aplicações Práticas (para IA)

Vetores e matrizes são a base de embeddings, operações de atenção e redes neurais. Autovalores e decomposição SVD explicam PCA, redução de dimensionalidade e interpolação em espaços latentes.
