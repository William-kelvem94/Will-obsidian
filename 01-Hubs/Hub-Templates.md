## Quando usar cada um

- Use nota atômica para conceito pequeno.
- Use nota de estudo para aprendizado contínuo.
- Use ADR para decisão difícil de reverter.
- Use runbook para operação repetível.
- Use bug report para problema reproduzível.
- Use postmortem para falha, incidente ou aprendizado importante.

## Regra de template

Todo template deve ter:

- objetivo;
- campos mínimos;
- exemplo ou instrução;
- links relacionados;
- resumo para IA quando fizer sentido.
