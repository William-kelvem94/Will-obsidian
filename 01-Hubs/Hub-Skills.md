## Regra de skill boa

Uma skill deve ter:

- objetivo;
- quando usar;
- pré-requisitos;
- exemplos;
- limitações;
- checklist;
- links para projetos onde foi aplicada.

## Próximas melhorias

- Criar matriz de proficiência.
- Relacionar cada skill a projetos reais.
- Criar trilhas de estudo por habilidade.
- Separar skills conceituais de skills operacionais.
