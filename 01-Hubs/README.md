## Regras

- hubs são pontos de navegação, não depósitos de conteúdo;
- cada domínio deve ter README ou INDEX;
- conteúdo novo segue a estrutura numerada;
- legado fica preservado em 08-Arquivo;
- fontes brutas ficam em 11-Dados-Brutos;
- regras e configurações ficam em 09-Sistema;
- alterações estruturais devem ser registradas em Operações do Vault.
