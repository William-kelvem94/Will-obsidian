## Regra de organização para projetos

Cada projeto importante deve ter:

- README;
- objetivo;
- status;
- stack;
- decisões;
- riscos;
- próximos passos;
- links para conhecimento usado;
- templates de bug, ADR ou postmortem quando necessário.

## Estrutura ideal de projeto

```txt
Nome-do-Projeto/
├── README.md
├── Decisoes/
├── Bugs/
├── Estudos/
├── Runbooks/
├── Reunioes/
└── Roadmap.md
```
