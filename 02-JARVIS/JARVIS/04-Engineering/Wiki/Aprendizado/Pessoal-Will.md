# Estilo Pessoal — Will

> Perfil comportamental e preferências de Will descobertas durante interações com o Jarvis. Útil para personalizar respostas e recomendações.

---

## 🛠️ Preferências de Ferramentas

| Categoria | Ferramenta | Observação |
|---|---|---|
| Editor | VS Code + Copilot | Prefere produtividade com AI integrada |
| Terminal | PowerShell | Shell principal no Windows |
| Gerenciador de pacotes | pnpm | Mais rápido e eficiente que npm/yarn |
| Contêineres | Docker Desktop | Para desenvolvimento local |
| LLM Local | Ollama | Usado para testes e experimentos offline |
| Agentes | LiveKit | Para agentes de voz e visão |

## 💖 Stack Favorita

- **Frontend:** Next.js + React
- **Backend:** FastAPI (Python) / Node.js
- **Banco de Dados:** SQLite para dev, PostgreSQL para prod
- **Infra:** Docker + Docker Compose
- **AI/ML:** Python, Ollama, LangChain
- **Obsidian:** Plugin Dataview + Templater para automação de notas

## 💬 Padrões de Comunicação

- Prefere respostas diretas e concisas
- Gosta de exemplos práticos em vez de explicações teóricas longas
- Prefere que o Jarvis aja proativamente em vez de pedir permissão para tudo
- Valoriza organização e documentação clara
- Comunicação em português (PT-BR) para contextos pessoais, inglês para técnico

## ⏰ Horários de Produtividade

- **Manhã:** Alta energia — tarefas complexas e arquitetura
- **Tarde:** Energia média — codificação e revisão
- **Noite:** Baixa energia — documentação, organização, tarefas leves

## ✍️ Estilo de Código

- Prefere TypeScript sobre JavaScript para projetos frontend
- Gosta de interfaces e tipos explícitos
- Prefere funções puras e imutabilidade
- Usa Prettier + ESLint para formatação consistente
- Comentários apenas quando a intenção não é óbvia
- Prefere composição sobre herança

## ⚠️ Gatilhos de Frustração

- Ferramentas que quebram backwards compatibility sem aviso
- Documentação desatualizada ou inexistente
- Processos manuais repetitivos que poderiam ser automatizados
- Perder contexto ou progresso por falta de versionamento
- Decisões tomadas sem considerar manutenção a longo prazo
- Bibliotecas com dependências excessivas ou conflitantes

## 🎯 Metas e Motivações

- Construir sistemas que realmente resolvem problemas reais
- Automatizar tudo que é repetitivo
- Criar um segundo cérebro funcional com o Jarvis
- Evoluir constantemente — aprender com erros e iterar
