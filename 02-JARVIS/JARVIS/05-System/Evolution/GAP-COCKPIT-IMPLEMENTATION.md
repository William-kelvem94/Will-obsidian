# Cockpit & Dashboards — Implementação Avançada no Obsidian

## Status atual

## Instruções Avançadas
1. Instale Morning OS, Buttons Panel e Canvas pela Community Plugins.
2. Monte widgets: tasks, KPIs de vault, links Wiki, status de squads.
3. Use Templater+Dataviewjs para cards automáticos "top projetos", cards warning, Info-Boxes.
4. Opcional: Scripts Python/JS exportam métricas automáticas para widgets do painel.
