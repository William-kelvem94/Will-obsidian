# Guia — Badges e Legenda Visual para Automação/Workflow

Use #automated para identificar arquivos, relatórios e painéis criados/atualizados por scripts (bots, plugins, rotinas Dataview, scripts shell).
Use #workflow para indicar workflows, pipelines e rotinas automáticas documentadas (inclusive se parte manual).

**Como preencher:**
```yaml
---
title: "Auto-Report Semanal"
tags: [relatorio, automated, workflow]
date: 2026-05-24
status: auto
---
```

**Dicas:**
- Sempre linke estes arquivos/painéis no [[INDEX]] ou no painel de dashboards.
- No topo do próprio .md/script, coloque badge visual: `#automated #workflow`
- Adicione breve explicação no README da área ou na documentação dos scripts.
