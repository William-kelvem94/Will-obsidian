# Memory Curation for Agents

Memory curation for agents e a habilidade de decidir o que deve ser lembrado, por quanto tempo e em qual forma. O objetivo e dar continuidade ao agente sem transformar historico em ruido.

## O Que Curar

- Decisoes tecnicas confirmadas.
- Preferencias estaveis do usuario.
- Comandos de projeto verificados.
- Erros recorrentes e diagnosticos.
- Mapas de arquivos e responsabilidades.

## O Que Nao Promover

- Hipoteses nao testadas.
- Logs brutos sem sintese.
- Preferencias momentaneas.
- Dados pessoais sem necessidade operacional.
- Estado temporario que muda a cada sessao.

## Fluxo de Curadoria

1. Capturar o evento com data e origem.
2. Classificar como episodico, semantico ou descartavel.
3. Consolidar em linguagem objetiva.
4. Linkar com projeto, skill ou conceito.
5. Revisar periodicamente memorias antigas.

## Criterio de Qualidade

Uma memoria boa permite que o agente tome uma decisao melhor no futuro. Se ela nao muda nenhuma decisao, provavelmente e ruido.
