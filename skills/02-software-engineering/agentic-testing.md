# Agentic Testing

## Regra de Ouro

Teste deve falhar antes e passar depois.

## Heuristicas

- unit para logica e bordas
- integration para boundaries reais
- e2e para poucos fluxos criticos

## Anti-padroes

- mocks demais
- asserts genericos
- testes acoplados em detalhes internos
