# Agentic Code Review

## Foco

- bugs e edge cases
- contratos e compatibilidade
- seguranca e privacidade
- observabilidade
- testes e validacao

## Perguntas Chave

- o que muda no comportamento?
- o que pode quebrar em producao?
- como validar rapidamente?

## Resultado

Comentarios curtos com risco + evidencia + sugestao minima + validacao.
