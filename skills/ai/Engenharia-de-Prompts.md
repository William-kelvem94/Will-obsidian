# Engenharia de Prompts

Prompt engineering é a prática de formular consultas para modelos de linguagem de forma precisa, clara e orientada ao resultado.

## Por que é importante?

Prompts bem construídos aumentam a precisão, a consistência e a utilidade das respostas de LLMs.

## Nível de Competência Atual

Avaliar tipos de prompt como direct prompts, few-shot, chain-of-thought e prompt templates.
