# Generative Models

Modelos generativos são arquiteturas que aprendem a criar novos exemplos semelhantes aos dados de treinamento.

## Por que é importante?

GANs, VAEs e modelos de difusão são centrais para IA criativa, síntese de dados e extensões multimodais. Para WILL, essa skill permite entender como gerar conteúdo, dados sintéticos e melhorar pipelines de RAG com exemplos de alta qualidade.

## Nível de Competência Atual

Conheço conceitos de geração adversarial, variável latente e processos de difusão reversa.
